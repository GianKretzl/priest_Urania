# Pasta Public - Arquivos Estáticos

## Logo do Sistema

Coloque a imagem do logo com o nome `logo.png` nesta pasta.

A imagem será exibida em:
- Sidebar (menu lateral)
- Página inicial
- Outras páginas do sistema

**Formato recomendado:** PNG com fundo transparente
**Dimensões recomendadas:** 800x800 pixels ou maior (o sistema redimensiona automaticamente)
